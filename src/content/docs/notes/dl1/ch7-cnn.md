## 합성곱 (Convolution) 계층

- **특징 맵 (feature map)**: 합성곱 계층의 입출력 데이터
- **필터**: $n \times m$ 크기의 가중치

### 합성곱 순서

1. 입력 위에서 **윈도우**를 이동시킨다.
2. 겹친 부분과 필터의 원소끼리 곱해서 모두 더한다. (**단일 곱셈-누산**)
3. 모든 입력을 다 돌 때까지 반복한다.

예) $4 \times 4$ 입력에 $3 \times 3$ 필터를 적용하면, 윈도우가 ①②③④ 네 위치에 놓이므로 출력은 $2 \times 2$ 가 된다.

- **필터 = 가중치**
- **편향**은 하나의 값으로, 출력의 각 칸에 모두 더해진다.

## 패딩 (Padding)

입력 데이터 주변을 특정 값(보통 0)으로 **감싼다.**

예) $(2, 2)$ 입력에 폭이 1인 패딩 → $(4, 4)$

- 주로 **출력 크기를 조정**하기 위해 사용한다.
- 합성곱은 하면 할수록 입력의 크기를 줄이기 때문에, 패딩으로 크기를 유지할 수 있다.

## 스트라이드 (Stride)

**필터를 적용하는 간격**

예) $4 \times 4$ 입력에 $2 \times 2$ 필터, stride = 2 → 2칸씩 이동하므로 출력은 $2 \times 2$

## 다차원 (다채널) 합성곱 연산

입력이 여러 장(채널)이면 → 필터도 채널 수만큼 여러 장이 된다.
하나의 입력 = **블록(3차원) 형태**가 된다.

배치를 포함한 CNN 레이어 구조:

$$
\underset{(N,\,C,\,H,\,W)}{\text{입력}} \;\circledast\; \underset{(FN,\,C,\,FH,\,FW)}{\text{필터}}
\;\longrightarrow\; \underset{(N,\,FN,\,OH,\,OW)}{\text{출력}}
$$

$$
\underset{(N,\,FN,\,OH,\,OW)}{\text{출력}} + \underset{(FN,\,1,\,1)}{\text{편향}}
\;\longrightarrow\; \underset{(N,\,C,\,OH,\,OW)}{\text{다음 층 입력}} \quad (C = FN)
$$

- 필터를 $FN$ 개 쓰면 출력 채널도 $FN$ 개가 된다.
- 편향은 $N$ 개 데이터 모두에 똑같이 적용된다. (브로드캐스트)
- 출력의 채널 수 $FN$ 이 다음 층의 입력 채널 수 $C$ 가 된다.

## 풀링 계층

가로·세로 방향의 공간을 줄이는 연산.

- **최대 풀링** (주로 사용): 한 윈도우 안의 **최댓값**을 구한다.
- **평균 풀링**: 한 윈도우 안의 **평균값**을 구한다.

> 풀링의 윈도우 크기 = 스트라이드로 두는 것이 보통이다. (**겹치는 부분 없게!**)

풀링의 특징
- 학습해야 할 매개변수가 없다.
- **채널 수가 변하지 않는다.** → 각 채널마다 따로 계산하기 때문
- 입력의 작은 변화에 영향을 적게 받는다. (**강건함**)

> **im2col 함수**: 입력 데이터를 필터 계산에 편하도록 2차원 행렬로 펼치는 함수. 전체 내용은 코드 참고.
